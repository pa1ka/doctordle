# Докторли

[Открыть игру](https://pa1ka.github.io/doctordle/)

Диагностическая игра для врачей: случай дня, пять закрытых подсказок и шесть попыток. Каждая ошибка или пропуск открывает следующую подсказку.

- Главный экран открывает случай дня; архив, статистика и тема находятся в меню.
- Архив: новые, ошибки, закладки и пройденные случаи, по шесть карточек на странице.
- «Следующий случай» выбирает не открывавшуюся задачу, учитывая сохранённую историю. Случай дня общий и не меняет расписание из-за личного прогресса.
- Неудачные попытки можно повторить отдельно от ежедневного результата. Успешное повторение убирает задачу из ошибок.
- Названия диагнозов в архиве отображаются только для решённых случаев. Медицинские направления скрыты.
- Прогресс, заметки и настройки хранятся в localStorage браузера. Между устройствами и доменами они автоматически не переносятся.

28 случаев: 8 кратких самостоятельных изложений опубликованных клинических наблюдений с первоисточниками, остальные — учебные сценарии. Независимая медицинская редактура не проводилась. Игра не предназначена для принятия клинических решений.

## Разработка и публикация

Исходники игры — `game/`. `node scripts/build-pages.mjs` собирает статическую версию в `out/` без установки зависимостей. Проверки: `node --test tests/*.test.mjs`.

GitHub Actions проверяет и публикует `out/` при обновлении `main`. Для режима Pages `main / (root)` готовые файлы также находятся в корне: при изменениях их нужно обновлять из `out/` в том же коммите. Предпочтительный источник публикации в Settings → Pages — GitHub Actions.

`public/` и `app/route.ts` — генерируемые файлы исходной Worker-версии (`node scripts/prepare-game.mjs`). Серверный код сохранён для справки; статическая версия его не использует. «Консилиум» отключён.
