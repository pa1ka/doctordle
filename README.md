# Докторли

Русскоязычная игра: определите диагноз по пяти постепенно открывающимся подсказкам.

Сайт публикуется через GitHub Actions. Исходники игры: `game/`. Сборка: `node scripts/build-pages.mjs`. Тесты: `node --test tests/engine.test.mjs`.

28 случаев, включая 8 пересказов опубликованных клинических наблюдений с первоисточниками. Остальные случаи — учебные сценарии. Независимая медицинская редактура не проводилась.

Статическая версия работает без сервера; режим «Консилиум» отключён. Прогресс хранится в браузере и не переносится между доменами автоматически.
